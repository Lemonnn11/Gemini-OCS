# Pillmate
The Gemini web application assists the scientist in managing a science plan for telescope system management. 
## Table of Contents
* [Technologies](#technologies)
* [Features](#features)
## Technologies
The project is built with:
- HTML
- CSS
- React TS
- Java Spring Boot
## Features
- Authentication 
- Create, edit, and delete a science plan
- Validate, invalidate, submit a science plan
